## 版本事实规则

- 运行行为以当前代码、`VERSION` 和自动化测试为准；
- 每次发布必须对应唯一 commit/tag 和唯一制品哈希；
- 云端临时修改必须回传仓库，经审查后才能成为下一版本事实；
- 文件名中的 `final`、修改时间或聊天回复不能证明版本身份；
- 发布包与源码有差异时，先停止发布并完成差异审查。
